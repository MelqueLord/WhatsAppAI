# Skill: explicar implementação

1. Explique o problema e o comportamento resultante antes dos detalhes internos.
2. Relacione a solução aos requisitos e aos arquivos ou módulos reais.
3. Informe como foi validada e quais limites ou riscos materiais persistem.
4. Não exponha segredos, prompts completos ou dados pessoais nos exemplos.
