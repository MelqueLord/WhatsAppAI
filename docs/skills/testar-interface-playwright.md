# Skill: testar interface com Playwright

1. Priorize jornadas críticas: login, Inbox, assumir, responder, configuração e falhas visíveis.
2. Use dados de teste isolados e API ou provedores fake quando possível.
3. Confirme acessibilidade básica, comportamento responsivo, loading e recuperação de erro.
4. Não automatize operação destrutiva contra ambiente de cliente.
