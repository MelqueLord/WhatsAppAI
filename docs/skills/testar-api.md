# Skill: testar API

1. Valide autenticação, antiforgery, papel, tenant e contratos de erro.
2. Exercite entradas válidas, inválidas, duplicadas e concorrentes.
3. Para endpoints de webhook, valide assinatura, idempotência e processamento assíncrono.
4. Nunca use credenciais ou dados de clientes em testes automatizados.
