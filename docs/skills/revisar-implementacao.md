# Skill: revisar implementação

1. Compare o diff com a tarefa, os requisitos e critérios de aceite.
2. Confirme validação de entrada, autorização, concorrência e tratamento de falhas.
3. Revise migrations, contratos, logs, segredos, Outbox e documentação afetada.
4. Execute ou analise evidências de build, lint e testes relevantes.
