# Skill: investigar bug

1. Reproduza com dados sanitizados e defina comportamento esperado pelo requisito.
2. Siga correlation ID, estado da conversa, Inbox, Outbox e logs sanitizados conforme o fluxo.
3. Isole a causa e identifique teste de regressão antes de propor a correção.
4. Atualize spec, runbook ou ADR quando o defeito revelar uma lacuna documental.
