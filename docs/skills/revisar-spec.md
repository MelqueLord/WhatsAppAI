# Skill: revisar spec

1. Verifique se escopo, exclusões, atores, requisitos, critérios de sucesso e casos de borda são verificáveis.
2. Garanta IDs estáveis para histórias, requisitos e tarefas.
3. Cheque tenancy, segurança, janela de 24 horas, idempotência e LGPD quando aplicáveis.
4. Compare a especificação com código e documentos relacionados; reporte divergências explicitamente.
