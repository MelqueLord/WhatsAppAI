# Skill: revisar segurança

1. Identifique dados, segredos, atores e fronteiras afetadas.
2. Verifique autenticação, autorização, antiforgery, assinatura, rate limit e mascaramento quando aplicáveis.
3. Garanta que não há segredo em banco, resposta, log, fixture ou código.
4. Confirme testes negativos e atualize o modelo de ameaças ou checklist se o risco mudar.
