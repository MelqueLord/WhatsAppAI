# Contexto: projeto

O WhatsApp AI Manager é um SaaS multiempresa para atendimento no WhatsApp. Cada tenant tem Inbox, operadores, linhas, configuração de automação e conhecimento próprios. A plataforma busca reduzir o esforço de atendimento sem se transformar em CRM, construtor genérico de bots ou plataforma multicanal.
