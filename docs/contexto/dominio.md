# Contexto: domínio

Os conceitos centrais são Tenant, usuário e membership, linha WhatsApp, contato, conversa, mensagem, Inbox/Outbox, fila, conhecimento, interação de IA, uso, auditoria e privacidade. Todo dado comercial é isolado pelo tenant e toda automação revalida a conversa antes de enviar.
