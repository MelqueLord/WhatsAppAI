# Documentação SDD

Esta estrutura contém a documentação canônica do projeto. `.specify/` mantém a constituição e os templates do Spec Kit.

| Área | Uso |
|---|---|
| [contexto/](contexto/) | Conhecer o produto e cada domínio antes de modificar código. |
| [regras/](regras/) | Aplicar limites de arquitetura, segurança, qualidade e operação. |
| [skills/](skills/) | Executar fluxos de análise, planejamento, revisão, testes e investigação. |
| [specs/](specs/) | Consultar comportamentos do produto organizados por capacidade. |
| [design/](design/) | Entender a solução técnica aprovada e seus limites. |
| [tasks/](tasks/) | Navegar o backlog canônico por frente de trabalho. |
| [decisoes/](decisoes/) | Localizar ADRs e suas consequências. |
| [pesquisa/](pesquisa/) | Localizar pesquisas e critérios de reavaliação. |

## Precedência

1. `AGENTS.md`
2. `.specify/memory/constitution.md`
3. A especificação, o plano e as tarefas aplicáveis em `docs/specs/`, `docs/design/` e `docs/tasks/`
4. ADRs canônicos em `docs/decisoes/`
5. Esta estrutura de navegação SDD
