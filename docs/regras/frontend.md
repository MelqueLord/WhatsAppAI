# Regras: frontend

- Usar React, TypeScript e Vite; não tratar ocultar telas como barreira de autorização.
- Exibir erros, loading, conflito de versão e estados de operação de forma acessível.
- Preservar atualizações em tempo real do tenant atual e invalidar dados após mutações.
- Validar build e testes afetados; não introduzir warning novo.
