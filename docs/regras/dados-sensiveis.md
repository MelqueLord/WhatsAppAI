# Regras: dados sensíveis

- Minimizar coleta e retenção de dados pessoais.
- Registrar finalidade e base legal; exigir consentimento apenas quando aplicável.
- Não registrar prompt completo, raciocínio interno ou PII sem mascaramento.
- Exportação, anonimização e exclusão devem ser auditáveis, idempotentes e tenant-scoped.

Fonte: [RIPD](lgpd-ripd.md), [checklist LGPD](lgpd-checklist.md) e [spec LGPD](../specs/uso-auditoria/controles-lgpd.md).
