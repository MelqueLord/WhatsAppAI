# Spec: transferir para humano

Pedido explícito de humano, risco, baixa confiança ou ausência de resposta segura geram handoff e modo `Human` quando permitido. Seleção de fila não é handoff: ela mantém o modo automático até assumir por operador.

Fonte: US-004, FR-014 e [spec de avisos por fila](../whatsapp/avisos-transferencia-fila.md).
