# Spec: configurar IA

TenantOwner configura diretrizes, perfil, conhecimento, filas, tags e limites de comportamento de sua empresa. PlatformAdmin administra credencial, provedor e modelo. Alterações usam versionamento otimista e não expõem API keys ao tenant.

Fonte: US-004, FR-004 e [spec de múltiplos provedores](provedores-multiplos.md).
