# Spec: criar tenant

PlatformAdmin cria tenant, TenantOwner inicial e configurações isoladas. A criação valida capacidade, plano e estado inicial; o link de ativação é exibido uma única vez para entrega manual. Segredos não retornam ao cliente.

Fonte: US-001, US-012 e [especificação-base](especificacao-plataforma.md).
