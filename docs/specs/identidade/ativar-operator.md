# Spec: ativar Operator

Operator ativa conta com convite válido, define senha e passa a acessar somente as filas permitidas no tenant. Token inválido, usado, revogado, substituído ou expirado não revela se o e-mail existe.

Fonte: US-008 e US-009 em [especificação-base](../plataforma/especificacao-plataforma.md).
