# Decisões arquiteturais

Os ADRs completos e canônicos estão neste diretório. Os nomes preservam a numeração e os nomes técnicos existentes para manter rastreabilidade com as especificações.

O [ADR-0015](0015-isolamento-servico-ponte-qr.md) define o isolamento da ponte QR. O [ADR-0016](0016-waba-template-ownership.md) define a WABA como fronteira tenant-scoped para catálogo e webhooks de templates.
O [ADR-0017](0017-no-contact-consent-gates.md) remove a coleta e a exigência de consentimento por contato no Marketing e na memória individual, preservando os controles gerais de privacidade.
