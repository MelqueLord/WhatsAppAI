# Pesquisa

Pesquisas existentes registram decisões e critérios de reavaliação. Não adote uma tecnologia nova sem atualizar pesquisa, especificação, plano e ADR quando necessário.

A [avaliação de padrões de indústria](avaliacao-padroes-industria.md) registra as evidências da revisão de 2026-09-13 e as encaminha ao incremento de correção.
