# Pesquisa: provedores de IA

Provedores ficam atrás de interface própria e retornam decisão estruturada. Alterar modelo, provider ou prompt requer avaliação de qualidade, segurança, handoff, p95 e custo; não há dependência de modelo no domínio.

Fonte: [decisões técnicas](decisoes-tecnicas.md), [política de IA](../regras/inteligencia-artificial.md) e [spec de provedores](../specs/ia/provedores-multiplos.md).
