# Especificações

Uma especificação registra a necessidade antes da solução. Identifique histórias de usuário com `US-###`, requisitos funcionais com `FR-###`, requisitos não funcionais com `NFR-###`, regras de negócio com `BR-###` e critérios de sucesso com `SC-###`.

Use [o template](./_template.md) para cada capacidade.
