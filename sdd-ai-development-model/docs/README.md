# Documentação do produto

Use esta árvore como memória durável do projeto. Cada documento deve ter um responsável, data de atualização e links para os artefatos relacionados.

- `contexto/`: cenário e limites existentes por domínio.
- `regras/`: políticas técnicas e de produto que se repetem entre capacidades.
- `specs/`: o que deve ser entregue e por quê.
- `design/`: como uma capacidade será construída.
- `tasks/`: trabalho executável e ordenado.
- `decisoes/`: decisões arquiteturais relevantes.
- `pesquisa/`: fontes, experimentos e conclusões.
