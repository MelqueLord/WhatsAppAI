# Fluxos repetíveis

As skills executáveis ficam em `.agents/skills/`. Documente aqui convenções locais, comandos de verificação e fluxos que a equipe repete. Cada fluxo deve informar quando usar, entradas, saída esperada e como validar o resultado.

Fluxo padrão para uma capacidade:

1. especificar;
2. esclarecer;
3. planejar;
4. gerar tarefas;
5. analisar consistência;
6. implementar;
7. convergir documentos e código.
